# Divadlo Kalich redesign

Směr:

- zachovává předchozí Kalich návrh, který fungoval,
- více se přibližuje UX VČD: důraz na program, rychlé hledání představení a nákup vstupenek,
- header je klasický statický, bez sticky chování,
- zachováno vyhledávání v hlavní navigaci,
- přidán event finder: název / datum / scéna,
- zachovány skutečné barvy, loga, fotografie, repertoár, tři scény, aktuality a praktické informace Divadla Kalich,
- žádné eyebrow texty, SaaS bloky, KPI, generické AI slogany ani dekorativní AI prvky.

Použito:

- Bootstrap 5.3.8
- Bootstrap Icons 1.13.1
- Swiper 11
- Roboto + Merriweather
- vanilla JavaScript
